# Computational Notebooks

A collection of self-contained Jupyter notebooks covering applied mathematics, machine learning, deep learning, scientific computing, and numerical modeling.

The repository contains selected academic, research, and applied projects. Each notebook includes a problem statement, data analysis, mathematical or algorithmic methodology, model development, metric selection, experimental results, visualizations, and conclusions.

## Areas of Focus

- Applied mathematics and numerical methods
- Machine learning and deep learning
- Computer vision
- Recommender systems
- Physics-Informed Neural Networks
- Probability and reinforcement learning
- Scientific computing
- Model evaluation and metric selection
- MLOps and reproducible experimentation
